# Звіти з лабораторних робіт (Frontend)

Цей репозиторій містить виконані лабораторні роботи з курсу Frontend-розробки.

---

## Лабораторна робота №1: Налаштування робочого середовища

### Мета
Навчитись налаштовувати робоче середовище для розробки, використовувати git, створювати базові проєкти за допомогою React (Vite) та оформлювати звіти.

### Завдання
1. **Встановлення та оновлення програмного забезпечення:**
   - Встановлено Node.js та git до останніх стабільних версій.
   - Налаштовано редактор коду (Visual Studio Code).
2. **Робота з репозиторієм:**
   - Створено та клоновано репозиторій для лабораторних робіт.
3. **Створення React-проєкту:**
   - Створено новий React-проєкт за допомогою Vite (папка `laba1`).
4. **Оформлення звіту та відправка:**
   - Налаштовано Git, збережено історію комітів та відправлено код на GitHub.

---

## Лабораторна робота №2: Інтерактивний світлофор на React

### Мета
Ознайомитись з компонентним підходом у React, навчитись працювати зі станом компонентів (`useState`), передавати пропси (props) та стилізувати інтерфейс.

### Що було зроблено (Завдання)
1. **Розробка структури компонентів:**
   - Створено компонент `Light.jsx` для відображення окремого кольору світлофора.
   - Створено компонент `StatsBar.jsx` для виводу статистики взаємодій.
   - Створено головний компонент `TrafficLights.jsx`, який об'єднує світлофор та панель статистики.
   - Головний файл `App.jsx` налаштовано як контейнер для всього застосунку.

2. **Робота зі станом (`useState`):**
   - Реалізовано збереження поточного активного кольору світлофора.
   - Налаштовано лічильник кліків для кожного окремого кольору (червоний, жовтий, зелений).
   - Додано функціонал зміни орієнтації світлофора (вертикальна або горизонтальна) за допомогою кнопки.

3. **Стилізація:**
   - Додано темну тему для загального фону сторінки.
   - Налаштовано відцентрування елементів та адаптивні відступи.
   - Додано візуальні ефекти (світіння `box-shadow`) для активного кольору світлофора.

### Результат
Створено повністю робочий інтерактивний застосунок. 

 **Скріншоти результатів виконання лабораторної роботи №2 (в різних станах та орієнтаціях) знаходяться у папці `assets`.**
