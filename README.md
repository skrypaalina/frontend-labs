Цей репозиторій містить виконані лабораторні роботи з курсу Frontend-розробки.

## Лабораторна робота №1: Налаштування робочого середовища

### Мета
Навчитись налаштовувати робоче середовище для розробки, використовувати git, створювати базові проєкти за допомогою React (Vite) та оформлювати звіти.

### Завдання
1. **Встановлення та оновлення програмного забезпечення:**
   - Встановлено Node.js та git до останніх стабільних версій.
   - Налаштовано редактор коду (Visual Studio Code).
2. **Робота з репозиторієм:**
   - Створено та клоновано репозиторій для лабораторних робіт.
3. **Створення React-проєкту:**
   - Створено новий React-проєкт за допомогою Vite (папка `laba1`).
4. **Оформлення звіту та відправка:**
   - Налаштовано Git, збережено історію комітів та відправлено код на GitHub.

## Лабораторна робота №2: Інтерактивний світлофор на React

### Мета
Ознайомитись з компонентним підходом у React, навчитись працювати зі станом компонентів (`useState`), передавати пропси (props) та стилізувати інтерфейс.

### Що було зроблено (Завдання)
1. **Розробка структури компонентів:**
   - Створено компонент `Light.jsx` для відображення окремого кольору світлофора.
   - Створено компонент `StatsBar.jsx` для виводу статистики взаємодій.
   - Створено головний компонент `TrafficLights.jsx`, який об'єднує світлофор та панель статистики.
   - Головний файл `App.jsx` налаштовано як контейнер для всього застосунку.

2. **Робота зі станом (`useState`):**
   - Реалізовано збереження поточного активного кольору світлофора.
   - Налаштовано лічильник кліків для кожного окремого кольору (червоний, жовтий, зелений).
   - Додано функціонал зміни орієнтації світлофора (вертикальна або горизонтальна) за допомогою кнопки.

3. **Стилізація:**
   - Додано темну тему для загального фону сторінки.
   - Налаштовано відцентрування елементів та адаптивні відступи.
   - Додано візуальні ефекти (світіння `box-shadow`) для активного кольору світлофора.

### Результат
Створено повністю робочий інтерактивний застосунок. 

 **Скріншоти результатів виконання лабораторної роботи №2 (в різних станах та орієнтаціях) знаходяться у папці `assets`.**
 ## Лабораторна робота №3: Поведінка в часі, ефекти та анімація

### Мета
Навчитися додавати до React-застосунку поведінку, яка керується часом. Засвоїти роботу з хуком `useEffect`, функціями очищення та керуванням залежностями ефекту без створення паралельних таймерів.

### Що було зроблено
1. **Рефакторинг стану фаз:** 
   - Замінено зберігання поточного кольору на збереження індексу фази (`phaseIndex`).
   - Створено єдиний цикл `['red', 'yellow', 'green', 'yellow']`, з якого динамічно вираховується поточний колір.
2. **Автоматичний режим (`useEffect`):**
   - Додано стан `isAutomatic`, який керується кнопками "Запустити" та "Зупинити".
   - Реалізовано `useEffect`, який синхронізує браузерний таймер (`setInterval`) зі станом `isAutomatic`.
   - Забезпечено коректне очищення таймера (`clearInterval`) для запобігання витоку пам'яті та дублюванню таймерів (навіть у Strict Mode).
3. **Збереження логіки ручного керування (з ЛР2):**
   - Під час автоматичної роботи ручні натискання заблоковані.
   - Автоматична зміна фаз не впливає на лічильники статистики.
   - Після зупинки циклу ручний режим та статистика продовжують працювати коректно.
4. **Анімація:**
   - Зміна активного сигналу супроводжується плавним CSS-переходом (`transition`), що відображає зміну стану React, а не керує нею.
 
## Лабораторна робота №4: Маршрутизація в React (React Router) та управління станом

**Мета**
Опанувати налаштування клієнтської маршрутизації в односторінкових застосунках (SPA) за допомогою бібліотеки `react-router-dom`, навчитися створювати навігацію між сторінками та працювати з глобальним станом через Context API.

**Завдання**
1. Встановити та налаштувати бібліотеку `react-router-dom` для забезпечення маршрутизації.
2. Створити базові сторінки застосунку: `HomePage`, `TrafficLightPage`, `StatsPage`, а також сторінку для обробки неіснуючих маршрутів — `NotFoundPage` (404).
3. Створити загальний макет сторінки (`AppLayout`), який містить навігаційне меню для переходу між розділами.
4. Реалізувати глобальне сховище даних за допомогою `TrafficLightsContext` для збереження та передачі стану світлофора між різними компонентами та сторінками.

**Короткий опис реалізації:**
У цій роботі було додано багатосторінковість у React-застосунок без перезавантаження сторінки в браузері. За допомогою компонентів маршрутизації налаштовано переходи між Головною сторінкою, Світлофором та Статистикою. Логіку управління світлофором винесено в React Context, що дозволило відокремити дані від UI та легко діставати до них доступ з будь-якої сторінки (наприклад, для відображення статистики натискань).
